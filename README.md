# 基于STM32与FreeRTOS的工业环境数据采集网关

## 📖 项目简介
本项目模拟工业现场的边缘数据采集节点。以 STM32 为核心控制器，搭载 FreeRTOS 实时操作系统，实现环境参数（温湿度）的采集、本地 OLED 显示、超限自动风扇控制。同时，设备作为 Modbus RTU 主站，通过 RS485 总线将数据打包上报至 PC 端上位机。

## 🛠️ 硬件与软件环境
* **主控芯片**：STM32（正在核对型号）
* **操作系统**：FreeRTOS
* **开发环境**：STM32CubeMX + Keil MDK / STM32CubeIDE
* **主要外设**：I2C(温湿度)、ADC(NTC)、PWM(风扇)、UART(RS485通信)

## 🚀 核心功能分解
1. **多任务调度**：基于FreeRTOS创建采集、显示、通信等任务，通过消息队列实现任务间数据交互。
2. **本地闭环控制**：监测温度超限时，自动调节PWM占空比驱动风扇降温。
3. **工业协议通信**：基于Modbus RTU协议开发底层驱动，实现半双工方向控制、CRC校验及超时重发机制。
